# WorldWar: Генштаб

Глобальная военно-политическая стратегия о 1936–1948 годах для Android, в жанре Hearts of Iron IV, но со своим кодом, картой и данными. Вы управляете любой страной мира 1 января 1936 года: экономикой, наукой, армией, авиацией, флотом и дипломатией, и время идёт непрерывно, по дням. Интерфейс сделан под телефон: всё управление касаниями, игра работает в портретной и альбомной ориентации и без интернета.

**Установка:** скачайте [`release/WorldWar-Genshtab.apk`](release/WorldWar-Genshtab.apk), откройте файл на телефоне и разрешите установку из этого источника. Нужен Android 7.0 или новее.

## Что есть в игре

**Карта мира.** 621 сухопутный регион в границах 1936 года и 86 морских зон. Границы построены по данным Natural Earth: Данциг, Восточная Пруссия, Судеты, Бессарабия, Маньчжоу-го, китайские милитаристы, колониальные империи. В каждом регионе есть рельеф (9 типов), население, очки победы, заводы, инфраструктура, аэродромы, порты, укрепления, ПВО и месторождения шести ресурсов: нефти, стали, алюминия, каучука, вольфрама и хрома. Есть 7 режимов карты: политическая, рельеф, промышленность, снабжение, дипломатия, авиация и флот.

**78 стран** со своими лидерами, идеологией, промышленностью, армиями, ВВС и флотами на 1936 год. У всех стран, кроме испанских националистов, которые появляются по сценарию, есть исторические колонии, марионетки и альянсы: Союзники, Коминтерн, Сфера сопроцветания, Объединённый фронт Китая и Ось, которая создаётся по ходу игры.

**Экономика:**
- гражданские заводы строят, военные производят снаряжение, верфи спускают корабли;
- эффективность производственных линий растёт со временем и падает при перестройке;
- ресурсы добываются в регионах и закупаются через торговлю, их нехватка снижает выпуск;
- можно строить синтетическое топливо, инфраструктуру, укрепления, аэродромы, порты и ПВО;
- бомбардировки разрушают промышленность, а на оккупированных землях выпуск ниже.

**Политика:** политическая власть, стабильность, поддержка войны и поддержка четырёх идеологий. Есть законы об экономике, призыве и торговле, 16 советников и национальные особенности (Великая депрессия, изоляционизм США, чистки в РККА и другие).

**Исследования:** 121 технология в 8 отраслях. Это пехота, артиллерия, бронетехника, авиация, флот, промышленность, электроника (вплоть до атомной бомбы) и взаимоисключающие сухопутные доктрины. Исследование технологий раньше их года идёт медленнее.

**Национальные цели:**
- проработанные деревья для Германии, СССР, Великобритании, Франции, Италии, Японии и США;
- общее дерево для остальных стран;
- исторические события и ультиматумы: Испанская гражданская война, аншлюс, Мюнхен, Мемель, пакт о ненападении, Данциг, Зимняя война и Московский мир, Прибалтика, Бессарабия, Венский арбитраж, Индокитай, Пёрл-Харбор, ленд-лиз.

**Сухопутная война:**
- шаблоны дивизий из 10 типов батальонов и 5 рот поддержки;
- характеристики: атака по пехоте и технике, оборона, прорыв, организация, броня и пробитие, ширина фронта, снабжение;
- бои с учётом рельефа, окапывания, укреплений, атаки с нескольких направлений, авиаподдержки и снабжения;
- отступление, окружение, потери снаряжения и людей, пополнение со склада.

**Генштаб:** для каждого фронта вы задаёте режим (оборона, наступление или прорыв) и приоритет, а штаб сам распределяет дивизии и атакует там, где есть перевес. Можно командовать и вручную: коснитесь значка войск, затем региона.

**Снабжение:** ёмкость регионов ограничена, нужна связь со столицей или с портом. За морем снабжение идёт конвоями.

**Авиация:** авиакрылья базируются на аэродромах и имеют радиус действия. Есть превосходство в воздухе, поддержка войск, стратегические бомбардировки, удары по флоту и атомные удары.

**Флот:**
- флоты с эсминцами, крейсерами, линкорами, авианосцами и подлодками;
- миссии: патрулирование, рейдерство и охрана конвоев;
- морские бои и господство на море;
- проливы и каналы (Босфор, Гибралтар, Суэц, Панама, Малакка), которые закрывает тот, кто контролирует берег;
- морские десанты.

**Дипломатия:**
- улучшение отношений, пакт о ненападении, гарантии, право прохода;
- альянсы: приглашение, вступление, выход;
- оправдание цели войны, объявление войны, мир без аннексий, отправка снаряжения;
- мировая напряжённость;
- капитуляция по потере очков победы, правительства в изгнании, мирные договоры (аннексия или марионетка), восстановление освобождённых стран.

**ИИ всех стран** строит, исследует, производит, набирает войска, ведёт фронты и десанты, управляет авиацией и флотом и вступает в альянсы. Без вмешательства игрока история обычно идёт близко к реальной: Польша падает осенью 1939-го, Бенилюкс — в 1940-м, «Барбаросса» начинается в июне 1941-го, Пёрл-Харбор — в декабре 1941-го. При этом каждая партия складывается по-своему.

**Министры:** науку, строительство, производство, набор войск, авиацию, флот и торговлю можно поручить автоматике.

**Прочее:** три уровня сложности, четыре ячейки сохранений и автосохранение раз в месяц и при сворачивании приложения. Есть журнал событий, статистика мира и встроенная справка.

## Управление

| Действие | Жест |
|---|---|
| Двигать карту | провести одним пальцем |
| Масштаб | развести или свести два пальца (или кнопки + / − справа) |
| Сведения о регионе | коснуться региона |
| Выбрать свои войска | коснуться значка дивизий |
| Марш или атака | при выбранных войсках коснуться региона-цели |
| Морская переброска или десант | выбрать войска в прибрежном регионе и коснуться региона за морем |
| Выбрать другой отряд, когда войска уже выбраны | долгое нажатие на него |
| Пауза и скорость | кнопки ▶ / ❚❚ и − / + внизу справа |
| Назад, закрыть окно | системная кнопка «Назад» |

Красные кружки слева подсказывают, что требует внимания: свободные заводы, ячейки исследований, войска без снабжения и так далее.

## Устройство проекта

```
web/            игра (JavaScript, без внешних библиотек)
  src/core/     симуляция: экономика, бои, снабжение, авиация, флот, дипломатия, ИИ
  src/data/     страны, технологии, законы, техника, цели, события, карта (map.json)
  src/ui/       интерфейс: карта на canvas, панели, меню
  public/       index.html, стили
android/        оболочка Android (WebView, файловые сохранения, полноэкранный режим)
tools/mapgen/   генератор карты из Natural Earth (Python)
tools/sim/      консольная симуляция мира без игрока: тесты и баланс
release/        готовый APK
```

## Сборка

Нужны Node.js 18+, JDK 17+ и Android SDK с пакетами `platforms;android-35` и `build-tools;35.0.0`.

```bash
cd web && npm install && npm run build        # собирает web/dist/www/app
cd ../android && ANDROID_HOME=~/Android/Sdk ./build-apk.sh ../release/WorldWar-Genshtab.apk
```

Скрипт `build-apk.sh` собирает и подписывает APK одними инструментами SDK (aapt2, javac, d8, apksigner), без Gradle и без загрузки зависимостей. Обычная сборка через Gradle тоже работает: `cd android && ./gradlew assembleRelease`, а APK появится в `android/app/build/outputs/apk/release/`.

Ключ подписи `android/keystore/worldwar.jks` (пароль `worldwar1936`) хранится в репозитории, чтобы любая сборка могла обновить уже установленную игру. Перед публикацией в магазине приложений замените его своим закрытым ключом.

Каждый push в GitHub Actions прогоняет тест-симуляцию и собирает APK (артефакт `WorldWar-apk`).

### Игра в браузере

После `npm run build` откройте `web/dist/www/app/index.html` в Chrome. Сохранения в браузере хранятся в localStorage.

### Симуляция и тесты

```bash
cd web
npm test                          # 4 года мира без игрока с проверками целостности и сохранения/загрузки
npm run sim -- --years 10         # летопись событий и сводка держав по годам
```

### Карта

`tools/mapgen/build_map.py` строит `web/src/data/map.json` из открытых данных [Natural Earth](https://www.naturalearthdata.com/) (общественное достояние). Правила переделки современных границ в границы 1936 года, число регионов на страну, морские зоны и проливы задаются в `tools/mapgen/config.py`.

```bash
pip install geopandas shapely pyogrio scipy rasterio
npm install -g mapshaper
# скачать и распаковать в ne/: ne_10m_admin_1_states_provinces, ne_10m_populated_places,
# ne_10m_geography_regions_polys, ne_50m_lakes, ne_50m_rivers_lake_centerlines
python3 tools/mapgen/build_map.py ne/ work/ web/src/data/map.json mapshaper
```
